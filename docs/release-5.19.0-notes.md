# Nodus 5.19.0

## New features

- New academic vaults start with your sources. Pick Zotero collections with their subcollections or your own files, then the AI that answers. Nodus prepares a few works and opens Research chat with a suggested question as soon as one is searchable.

- After the first cited answer, the guide offers See the ideas in this source. It extracts the ideas from the same document in one click. The lesson ends on one idea’s evidence and its place in the graph.

## Enhancements

- The backup setup offers Start now and protect it later. Nodus uses a folder of its own on this computer and keeps a first verified backup. A day later it reminds you to save the recovery kit.

- Nodus Link readers show their header actions as icons and gather filters in one menu. The Dictionary has an A to Z index on the edge of the screen.

- When Zotero does not answer, Nodus shows the two steps to enable its local API and checks again on its own every few seconds. An empty collection list no longer appears. The Zotero plugin is not needed to import. You see this when choosing collections and in Settings.

- An empty Library offers Bring from Zotero and Add files. You can start without looking for where sources are imported.

## Fixes

- In Manual mode, ideas that have a theme are indexed without errors. Before, they failed with an embedding source change error.

- The guide card no longer covers the close button of a large dialog it has just opened.

- With a local embedding model, questions no longer wait for document preparation to finish. Before, search could stay on Preparing search for several minutes.

- Documents read from Zotero count as prepared as soon as their text is indexed. Before, the first-answer guide kept waiting for them forever.
