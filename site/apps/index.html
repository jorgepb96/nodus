Nodus Apps

01 · What it is

Small software shaped around one real task.

A Nodus app is a focused HTML, CSS and JavaScript tool that runs inside a sandboxed part of the desktop application. It can keep its own local data, adapt to mobile or desktop screens and, where appropriate, support a temporary shared session.

Nodus Apps is not a separate mobile app or subscription service. It is included in the free Nodus desktop application from the Nodus Research project.

02 · How it works

Describe, test, adjust, keep.

01

Describe the job

Ask for a planner, calculator, classroom activity, research checklist, structured form, visual aid or another small tool with a clear purpose.

02

Review a working app

Nodus generates the interface and behaviour as a complete bundle, then opens it in an isolated preview where every control can be tested.

03

Request changes in plain language

Explain what should be clearer, what field is missing or how an interaction should change. Each revision keeps the app focused on the original task.

04

Use it locally or export it

Keep the app in your Nodus catalogue, download its source and ready-to-use version, or start a live QR session when participation is part of the design.

03 · What to build

Tools for the work between the big steps.

Research

Extraction forms, sampling helpers, coding checklists, source-comparison grids, fieldwork utilities and small calculators built around a particular method.

Teaching

Live brainstorms, topic distributors, anonymous polls, classroom games, activity timers and participation tools that students can join by QR.

Study

Revision planners, flashcard helpers, practice activities, concept sorters, progress trackers and tools shaped around one course or assessment.

Everyday utilities

Decision wheels, calculators, checklists, simple forms and other single-purpose tools that do not need a new account or cloud service.

05 · Sharing and privacy

Local by default. Shared only when you start a session.

Sandboxed execution

Each mini app runs inside an isolated frame rather than sharing unrestricted access to the rest of Nodus. Its saved data belongs to that app and stays local.

Temporary participation

For multiplayer apps, Nodus can host an ephemeral local session and show a QR code or PIN. Participants join the app, not the user's vault or Library.

Exportable source

A downloaded package contains a ready-to-run page plus the separate HTML, CSS and JavaScript, so the tool can be preserved, inspected and modified.

Your model choice

Creating or repairing an app uses the AI model configured in Nodus, including a compatible local model. Running an existing app does not require generation.

06 · Short answers

Nodus Apps, without the ambiguity.

01

What is Nodus Apps?

The built-in workspace for creating, testing, adapting and sharing small applications from inside Nodus.

02

Is it a separate Nodus app?

No. Nodus Apps is one part of the Nodus desktop application and uses the same free, open-source installation.

03

Can people join from a phone?

Yes, when an app supports participation. The host starts a temporary session and other people open it with a QR code or PIN.

04

Do generated apps belong to the user?

They remain in the user's local catalogue and can be downloaded as an inspectable package with their source files.
