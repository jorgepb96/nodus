# Nodus 5.18.1

## New features

- Download selected sections and podcast episodes from Nodus Link for offline use. Removing a download only deletes the iPhone or iPad copy. Desktop data is preserved.

## Enhancements

- Search ideas and themes in one field. Argument maps use native full screen on iOS, with controls aligned to the tab bar.

## Fixes

- Mobile connection appears under Application in Settings. Searching for Nodus Link, iOS, iPad or Android also finds this section.

- The linked reader receives Deep Research read marks and personal annotations. Related search uses the computer’s configured index, validates its current contract and requires no provider keys on iOS.
