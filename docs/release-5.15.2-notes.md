# Nodus 5.15.2

## New features

No changes in this section.

## Enhancements

- Voice filters follow the model and interface language until you change them. Your choices are remembered when you reopen the picker. The Listen balloon shows the active voice, and model downloads use an icon button.

## Fixes

- Ming splits text according to the space available alongside the reference recording. If a fragment exceeds the limit, it regenerates it in smaller parts before playback or saving to avoid dropping the end of the text.

- In My voices, the play button changes to pause while a recording plays. You can pause and resume from the same position. Playing another voice stops the previous one.
