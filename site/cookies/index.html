Cookies and local storage notice

This notice identifies the cookies and equivalent browser-storage technologies used by nodusresearch.com, their purposes and duration, and the means available to remove them.

Effective date: 31 August 2026.

1. Use of cookies and equivalent technologies

The project does not deliberately set HTTP cookies on nodusresearch.com. It has no Google Analytics, analytics container, advertising pixel, fingerprinting code or cross-site visitor identifier. Google Search Console ownership verification is not a visitor-tracking script and does not create a Search Console cookie on this website.

The website does use the browser's localStorage for limited functional purposes. Spanish and EU rules cover this type of terminal storage as well as conventional cookies, so it is documented here even when the stored value contains no personal visitor identifier.

2. First-party browser storage

These values support a feature used or selected by the visitor, store public cache data, or remember a local interface choice. They are not combined into a visitor profile, used for advertising or sent to the project.

3. Third-party content and storage

Public GitHub counters and contributor data, YouTube thumbnails, the Leaflet library supplied through unpkg, and CARTO map tiles can be requested as described in the website privacy notice. Those network requests are not used by Nodus Research to track visitors.

A YouTube player is created only after the visitor chooses a video. It uses the youtube-nocookie.com privacy-enhanced domain. YouTube may then use storage needed to operate the requested player under Google's rules; leaving the embedded player or opening YouTube directly subjects the visit to Google's own settings and policies.

GitHub, Google, unpkg and CARTO control any storage used on their own domains. Their practices can change independently, so their current notices and the browser's storage panel are the authoritative sources for third-party items.

4. Management, refusal and deletion

Local Nodi notes can be deleted inside the notes panel. All first-party items can also be removed using the browser's “site data”, “cookies and site data” or equivalent privacy settings for nodusresearch.com. Blocking local storage may prevent notes and read-state preferences from persisting, but the public content remains available.

Because the website currently has no non-essential analytics or advertising storage, it does not display a general consent banner. If a future version introduces non-essential storage, it must remain disabled until the visitor has received the required information and made a choice; this notice and the interface will be updated at that time.

Questions can be sent to contact@nodusresearch.com.
