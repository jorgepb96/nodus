03 · Citation formats

Ready to paste, still worth checking.

Adapt punctuation and capitalisation to the style guide used by your journal, institution or repository.

APA

Pérez Burgueño, J., & Nodus contributors. (2026). Nodus: Open-Source Research Workspace (Version 5.8.1) [Computer software]. Zenodo. https://doi.org/10.5281/zenodo.21515531

BibTeX

@software{perez_burgueno_nodus_2026,
  author    = {Pérez Burgueño, Jorge and Nodus contributors},
  title     = {Nodus: Open-Source Research Workspace},
  version   = {5.8.1},
  year      = {2026},
  publisher = {Zenodo},
  doi       = {10.5281/zenodo.21515531},
  url       = {https://github.com/jorgepb96/nodus/releases/tag/v5.8.1},
  license   = {AGPL-3.0-only}
}

Machine-readable citation. GitHub reads the repository's CITATION.cff, which carries the same version, release date, DOI, author, ORCID and licence.
