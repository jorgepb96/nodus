Website privacy

Nodus Research does not collect or maintain a database of website visitors. This page explains that limited statement and identifies the external services that technically deliver parts of the website.

Effective date: 31 August 2026.

1. Scope

This notice applies to the public pages, documentation, blog and browser demos served from nodusresearch.com. It does not govern the Nodus desktop application, which has its own detailed application privacy policy. The mobile apps have separate policies: Nodus Reader, Nodus Drift and Nodus Presenter.

The website is maintained by Jorge Pérez Burgueño as part of the personal and independent Nodus Research open-source project. Questions about this notice can be sent to contact@nodusresearch.com.

2. No visitor database

Nodus Research does not directly collect, receive or retain information that identifies ordinary visitors. The website has no accounts, registration, contact form, newsletter, advertising, behavioural analytics, tracking pixels or remote Nodi chat. The project therefore has no visitor records that can be searched by a person's name, email address or other identity.

Text entered into the website's Nodi notes and helper remains in the visitor's browser. The project does not receive a copy. The limited functional values stored by the website are described in the cookies and local storage notice.

Google Search Console is used only to understand how the public site appears in Google Search. Its ownership verification does not install Google Analytics, an analytics container or a visitor-tracking script. The project uses only aggregated search-performance reports and does not use them to identify or profile visitors.

3. Technical requests to external services

Displaying any website requires the visitor's browser to communicate with a hosting server. GitHub Pages hosts this website and GitHub states that it records visitor IP addresses for security. The project does not receive or have access to those IP logs. See the GitHub Pages data-collection notice and the GitHub General Privacy Statement.

The website also requests public repository, release and contributor information from GitHub. These requests may cause the visitor's browser to communicate directly with GitHub, including when a public contributor avatar is displayed.

Google and YouTube. The video catalogue can load YouTube thumbnail images. The embedded player is created only after the visitor chooses a video and uses YouTube's privacy-enhanced youtube-nocookie.com domain. See the Google Privacy Policy.

unpkg. The genealogy browser demo obtains the Leaflet map library from the unpkg content-delivery service. Opening that demo therefore creates a technical request to unpkg.

CARTO. When the map in the genealogy demo is displayed, map tiles are requested from CARTO's public tile service. See the CARTO Privacy Notice.

These providers may receive technical request information, such as an IP address, directly from the visitor's browser under their own privacy terms. Nodus Research does not use those requests to track visitors, cannot identify visitors from them and cannot retrieve the providers' technical logs. Following an external link is likewise a separate action governed by the destination service.

4. Direct correspondence

If a person voluntarily writes to contact@nodusresearch.com, the project necessarily receives the sender's email address, message and any information the sender chooses to include. That information is used only to read, answer and, where necessary, keep a reasonable record of the correspondence. It is not added to a marketing list, sold or used to profile the sender.

Correspondence is retained only for as long as reasonably necessary to deal with the message, protect the project or comply with an applicable legal obligation. A sender may ask for their correspondence to be deleted when there is no overriding reason to retain it.

5. Requests about personal data

Nodus Research cannot provide, correct, export or delete ordinary visitor records because it does not possess such records and cannot identify an ordinary visitor. Requests concerning information held independently by GitHub, Google, unpkg or CARTO must be addressed to the relevant provider.

If a request concerns direct email correspondence actually held by the project, it can be sent to contact@nodusresearch.com. The project may ask for only the information reasonably necessary to locate the correspondence and verify that it belongs to the requester. A person may also contact the Spanish Data Protection Agency (AEPD).

This notice may be updated when the website, its providers or the applicable rules change. The effective date at the top identifies the current version.
