# Nodus 5.15.3

## New features

- Narration adds Pocket TTS, Kyutai’s official engine that runs on the CPU. Its six-layer models include a default voice in seven languages and can clone a recording of up to twelve seconds without a transcript. Models download when you need them, downloads can be paused and resumed, and the audio is generated on your computer. Pocket TTS is available on Apple silicon, Windows and Linux.

## Enhancements

No changes in this section.

## Fixes

- Configure Recovery opens the wizard when you request it from Settings or from the update notice, even in an academic vault whose tutorial invitations are still pending. The result of the last automatic backup is shown in the interface language, including after you change language.

- Nodus Support is published again for Windows and Linux. The Windows installer keeps its signature check without inheriting incompatible PowerShell module paths, and the Linux packages use the names the app already accepts, so the signed download and repair flows work again.
