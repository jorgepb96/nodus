# Companion manuscript conflicts — source stage

New scene-text mutations include an optional `_mobileExpectedText` baseline. After canonical authored-link promotion, a different current scene rejects the mutation with `world_scene_text_conflict` and a concrete recovery message. Rejections preserve the device change without a successful receipt. Legacy clients that omit the baseline retain their previous contract; an already-matching requested text is harmless to replay. Device-only metadata does not become a SQL column.

The canonical shrink hook deduplicates an identical latest shrink preimage already submitted by the companion before its dependent text mutation. This retains Desktop's 40-word and half-loss threshold and its existing bounded snapshot history.
